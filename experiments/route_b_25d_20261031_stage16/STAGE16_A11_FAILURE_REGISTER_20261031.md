# Stage 16 A11 失敗分類與預防規則

**2026-10-31｜A11 工程 PASS，美術 FAIL，Formal Seal NO。**

F-A11-01：草地「像素改變比例」與「人眼視覺改善」無關。A11 142,642／178,655 草地像素變動（79.842%），但三頻道平均變動量只有 2.2432／255。不可使用改動像素數宣稱美術進度達標。

F-A11-02：隨機低頻色塊＋零散的 185 組微草葉、25 組花點，缺少群落組織與可辨識的地表構圖。1x 外觀接近 A10；32px 對照更明顯看出僅是輕微色彩改變。A11 不是完成的原生 ground3 風格野外地表。

F-A11-03：即使每一株都是合法貼地草葉，也不能靠隨機增加像素點數量創造 ground3 的豐富度。下一階段要的是「語意規劃過的群落形狀」，不是再堆更多獨立雜點。

F-A11-04：所有新圖都是確定性程序化像素生成，未運作 SD1.5／ComfyUI／ControlNet／IP-Adapter。不能以 A11 證明類神經網路的原生圖片生成能力成功。

F-A11-05：既有道路（44,321px）與外側過渡帶（3,328px）全部保留 0 改動，證明工程遮罩規則正確；仍無法給足夠的環境生態美術。道路與可編輯草地的驗收必須分開。

F-A11-06：地圖只有 Ground，沒有 PAR、碰撞、Godot 引擎或真實 RPG Maker VX 實機；原因是未通過美術 Gate，不是無條件 PASS。

**反覆錯誤停止規則：** A12 禁止繼續在 A11 隨機色塊強度／花點數量上做無上限迴圈。應該改為具有可驗證密度與形狀的分群植被語意藍圖，固定 A10 比較，32px/1x 肉眼驗收優先。
