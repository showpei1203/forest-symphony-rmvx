## Failure Log and stop conditions
- F01 **Source collision mismatch**: A10 candidate collision also describes 40×29 but refers to different Master. **NEVER import** or assign because of matching dimensions. A30 instead creates independent A11-source-locked draft with explicit `CANDIDATE_NOT_USER_COLLISION_APPROVED`.
- F02 **Godot JSON numeric type pitfall**: JSON parser returns `[40.0,29.0]`; GDScript direct array comparison with `[40,29]` falsely rejected. Fixed by explicit integer comparison after checking array shape.
- F03 **Tile physics data initialized before atlas registered**: `TileData.physics.size()=0` produced out-of-bounds errors even when generator printed success. Fixed order: attach atlas source to TileSet, create tile, then add physics layer, then create polygon; verify polygon count=1 and **no errors**.
- F04 **Duplicate embedded TileSet**: original scene packing copied the resource inside `.tscn`, so editor resource edits would drift. Fixed with `tileset.take_over_path()` after saving external `.tres`; scene now references one editable external TileSet.
- F05 **GDScript PackedByteArray does not provide `sha256_buffer()`**: private test crashed/hung, changed to compare exact encoded PNG buffer with `.hex_encode()`; test now quits with proper failure signaling.
- F06 **Screenshot false static animation**: first real Godot shots were frame-identical because `_physics_process()` immediately reset manually forced poses to idle. Deterministic capture script now disables physics *only for controlled image captures*, then forces frames. Actual native physics animation independently verified in 221 test. Real loop frame pixel differences observed.
- F07 **ART HOLD**: actor behind tree can appear as a detached white-haired head; occlusion still screen-row hand-tuned, no verified 3D model. A62 45° battle sprite is stylistically much lower resolution than current detailed A11 map and is not a four-direction travel animation. No shader/alpha trick declared ART PASS.
- F08 **COLLISION ART HOLD**: red debug candidate areas are approximate (some house/wood/land/water edges); 180 blocked cells do NOT mean remaining 980 are legally traversable. Manual field of view, shoreline, tree, terrain and doorway boundaries still need review and 1x art tests. No pathfinding or transition claimed.
