# FS A39 | Godot-controlled Actor01 breathing rig

Stage: A39 / 2026-11-14 / **Godot GPU runtime PASS, ART HOLD, official FS battle integration NOT_RUN**.

This isolated Godot 4.7.2 project is an actual running continuation of A38. It retains five unchanged A38 atlas animation profiles (RUN raw/tuned, IDLE R1/R2/calm) and adds a sixth **`idle_rig`**. `idle_rig` is NOT a Sprite Sheet generated by AI. It is a native Godot AnimationPlayer driving the `breath_phase` shader parameter on the original, unscaled A62-approved Actor01 64×64 PNG. The shader modifies only a few chest/shoulder texels sampled from the *same source pixels* (no recolor, no resynthesis).

## Use in Godot

Open `project.godot` in Godot 4.7.2. Run F6 to start `scenes/battle_animation_preview.tscn`. Key bindings: `1` AI R1, `2` curated AI calm, `3` AI R2, `4` RUN 8fps, `5` RUN 10fps, **`6` local Godot breathing rig**, `SPACE` pause, `+/-` speed. Right side is the idle actor; left side retains the original A35 RUN. `scenes/a39_rig_preview.tscn` is a separate approved-vs-AI-vs-rig comparison. `scenes/actor01_breath_rig.tscn` is the reusable rig scene. The actual multi-profile battle actor is `scenes/actor01.tscn` and script `scripts/fs_actor_animator.gd`.

The approved source is `assets/actor01_a62_approved_idle_source_64.png`, SHA256 `70a8e6aaddbad052e3ea12fe8def8be90fe8932f89154da3c93da98edfddea1e`. The A35 original RUN sprite sheet remains byte-identical (SHA256 `ec0c7a59fb5983f13b1b3385323218edf0e77c23890db074c18c6e114e74408b`). Other AI experiments in assets remain unmodified.
