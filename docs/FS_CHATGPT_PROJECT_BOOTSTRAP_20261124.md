## What this does not do

Project instructions can provide the startup rule to future chats IN THIS PROJECT. They cannot install a connector, grant a PC Bridge allowlist permission, automatically import a private Orca/Cherry Skill, or cause truly autonomous background work. A new chat must make actual read calls each time. Other projects/chats without the setting are not automatically covered.
